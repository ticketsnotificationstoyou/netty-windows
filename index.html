Netty

A lightweight VPN client for Windows supporting modern proxy protocols.

Features

🔌

Multiple Protocols

VLESS, VLESS Reality, VMess, Trojan, and Shadowsocks.

➕

Easy Server Setup

Add servers via clipboard, manual entry, or QR code scan.

🔀

Traffic Routing

Route or exclude traffic by IP/CIDR ranges and domain rules.

🔒

No Data Collection

Everything stays on your device. Nothing is sent anywhere.

🌐

Multilingual

Available in English, Russian, and Chinese (Simplified).

System Tray

Adding a Server

📋
From Clipboard

Copies a VPN link automatically from your clipboard.

✏️
Manual

Paste or type a link: vless://, vmess://, trojan://, ss://

📷
QR Code

Scan a QR code image from a file on your computer.

Traffic Routing

Click the routing button (grid icon) to open routing settings:

  • IP Exclusions — load a .txt file with IP/CIDR addresses (one per line)
  • Domains — enter domains one per line (e.g. .ru, example.com)
  • Action — choose: Direct / Via VPN / Block
  • When routing is active, the button glows orange and an orange badge appears on the main indicator.

Requirements

OS Windows 10 / 11 (x64)
Permissions Administrator rights (required for TUN mode)
